# Web Technology Assignment

## Course
U21CS501 - Web Technology

## Assignment I

This repository contains the implementation and documentation
for the Web Technology Assignment.

## Questions Covered

### Q1 - Fundamentals of the World Wide Web
HTML webpage explaining Internet, networks, URLs, domains,
web browsers, web servers and website working.

### Q2 - Student Admission Form
Responsive HTML5 and CSS3 admission form with multimedia
elements including image, audio and video.

### Q3 - Online Fashion Store
Attractive fashion-store homepage demonstrating CSS3
backgrounds, borders, text effects, animations and
multiple-column layout.

### Q4 - Student Grade Calculator
JavaScript program to calculate total, average, grade
and pass/fail status for five subjects.

### Q5 - Supermarket Billing System
JavaScript billing system for three products with a
10% discount when the total exceeds ₹2000.

## Technologies Used

- HTML5
- CSS3
- JavaScript
